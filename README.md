# Blackjack CLI

A command-line implementation of classic casino Blackjack (21) written in pure Python.

## Features
* **Full Deck Simulation:** Handles standard 52-card shoe mechanics and dynamic reshuffling.
* **Intelligent Hand Evaluation:** Dynamic Ace scoring (evaluates dynamically as 1 or 11 to prevent busts).
* **Dealer Rules:** Implements standard casino house rules (dealer stands on 17+, hits on 16 or lower).
* **Game Flow:** Supports Hit, Stand, Natural 21 checks, and edge-case tie resolution.

## Tech Stack
* **Language:** Python
* **Libraries:** Standard library only (`random`, `time`, `sys`)
